PUBLIC API
==========

Base URL: https://api-chat.wokki20.nl

All responses are JSON. Errors return: {"error": <code>, "message": "<reason>"}


AUTHENTICATION
--------------

This API uses OAuth 2.0. Include your access token in the Authorization header:

  Authorization: Bearer <your_access_token>


ENDPOINTS
---------

GET /help
    This page. No authentication required.

GET /authorize
    Authorization page. Lets users log in, in exchange for a code

NOTES
-----
- All responses use Content-Type: application/json, except the help page
- Standard HTTP status codes are used throughout
- Authentication is required on all endpoints unless stated otherwise
